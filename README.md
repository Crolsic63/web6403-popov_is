# Лабораторная работа № 4
Модернизация сайта
- **Flexbox**: главная страница (`index.html`), шапка и меню
- **Grid**: каталог скинов (`skins.html`), сетка 4 колонки
- **CSS-переменные**: все цвета заданы в `:root`
- **Анимация**: карточки скинов появляются по очереди, при наведении: блик и свечение
- **Форма**: страница входа (`login.html`), поля text, email, password, select, checkbox
- **ООП**: класс `LoginData` с конструктором и методом `printToConsole()`; при отправке формы создаётся объект и выводится в консоль
- **БЭМ**: классы вида `блок__элемент_модификатор`
